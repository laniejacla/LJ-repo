# Bloom Studio

Step-by-step picture guides that grow young artists, from first crayon lines to
real paintings. It is a standalone product and is built to drop into Flora later.

## What it does

- **16 subjects** in 4 groups: Animals, Ocean & Bugs, Plants, Sky.
- **4 levels**: Seedling (3–5, dotted lines to trace), Sprout (6–8), Blossom
  (9–11, helper shapes and shading), Full Bloom (12+, light source, values,
  highlights, texture).
- **5 techniques**: Drawing, Sketching (hatching and cross-hatching),
  Watercolor (wet-on-wet, layers, pen outline), Painting (sky in stripes, blend,
  block in, shadows, highlights, value check), Silhouette sunset.
- **12 feelings** for the face (happy, excited, calm, loving, silly, surprised,
  shy, sleepy, sad, scared, grumpy, no face). Each comes with how to draw it and
  a short "feelings talk" prompt.
- **Extras**: bow, party hat, flower crown, glasses.
- **Colors**: natural, pastel, or the child's own main color.
- **6 painted backgrounds**: golden sunset, moonlit sea, northern lights, cotton
  candy sky, sunny meadow, under the sea.
- **Color guide** for every picture: recipes using only red, yellow, blue, white
  and black, sky recipes stripe by stripe, and complementary "color friends".
- **Color Lab**: a mixing bowl with a target color to match, the painter's
  color wheel, tints and shades, warm and cool, and opposites.
- **Practice pad**: draw with a see-through version of the current step to
  trace, then turn it off and try alone.
- **My Gallery**: finished artwork, badges, and a "try this next" suggestion.
- **Read to me** reads each step out loud for children who can't read yet.

Every picture is generated from data, not image files. The swatches are computed
from their recipes with a painter's (RYB) mixing model, so the recipe a child
follows matches the color on screen.

## Files

| File | Purpose |
|---|---|
| `bloom-studio.html` | The module: styles, data and engine. No `<html>` wrapper. |
| `index.html` | Standalone page, generated by `tools/build-bloom-studio.sh`. |

Edit `bloom-studio.html`, then run `sh tools/build-bloom-studio.sh`.

## Adding it to Flora

The module uses Flora's own token names (`--paper`, `--card`, `--ink`,
`--moss`, `--sage`, `--clay`, `--line`), so inside Flora it follows Flora's
light and dark themes automatically. All of its CSS is under `.bs`.

1. Copy the `<style>` block and `<script>` block into Flora (or load them as
   `src/bloom-studio.js` and `src/bloom-studio.css`).
2. Add a sidebar entry to `NAV` in Flora's `index.html`, e.g.
   `{k:"art", t:"Bloom Studio", i:"art", go:"art"}`.
3. When that page renders, call `BloomStudio.mount(element)`.

Progress is saved in the browser under `bloom-studio:v1` and never leaves the
device, which keeps Flora's rule that a child's work goes nowhere but the
family's own devices and Drive.

## Adding a subject

Add an entry to `SUBJECTS`. Each part has a drawing step `s`, a paint order `z`
and an SVG shape on a 200 × 200 board. Set `face` (where the eyes and mouth go),
`head` (where a hat or bow sits) and `colors` (names from `LIB`). Helper shapes,
shading, watercolor, painting and silhouette versions are all generated.
